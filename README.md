# Questionário Esteticista - Genthe

## Passos para publicação

1. Criar a tabela no Supabase executando o arquivo `supabase_schema.sql` no SQL Editor do projeto `wlfxwtzjlbuzyigzspms`.
2. Criar o repositório `questionario-esteticista` na organização `gentedagenthe` no GitHub (branch `master`).
3. Subir todos os arquivos deste projeto para o repositório.
4. Conectar o repositório ao Vercel.
5. Configurar as variáveis de ambiente no Vercel:
   - `REACT_APP_SUPABASE_URL`
   - `REACT_APP_SUPABASE_ANON_KEY`
   - `REACT_APP_ADMIN_PASSWORD`
6. Publicar. O formulário fica disponível na raiz do domínio e o painel administrativo em `/admin`.
